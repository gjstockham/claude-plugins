# Naming grammar reference

A phonaesthetic naming grammar is far lighter than a conlang: a sound inventory plus a few patterns is enough to make names feel consistent and culturally distinct.

## Components
- **Onsets** — consonants/clusters a syllable may start with (e.g. k, kh, v, s, th, br). Restricting these is what gives a culture its "sound."
- **Nuclei** — vowels and diphthongs (a, e, i, o, u, ae, ei, ou).
- **Codas** — consonants a syllable may end with (often a smaller set than onsets; some cultures forbid codas entirely → open, vowel-final names).
- **Syllable shape** — e.g. CV, CVC, CCV. Names are 1–3 syllables typically.
- **Forbidden clusters** — combinations you never allow (keeps generation on-brand and avoids accidental ugliness).

## Phonaesthetic flavour (pick to match culture)

Sample names below are illustrative, not canon — derive each world's inventories from its own peoples and established names rather than copying these sounds.
- Harsh/martial: stops and back consonants (k, kh, g, t, dr), closed syllables, few open vowels → "Berke, Khadar, Orvath".
- Maritime/mercantile: liquids and sibilants, open syllables, flowing vowels → "Ilhara, Szelgar, Pelan".
- Pastoral/steppe: strong onsets, short names, guttural → "Khorl, Berke, Ordu".
- Northern/hard-land: clustered consonants, short vowels → "Ulf, Fenn, Rime".
- Agrarian/settled: balanced CVC, softer → "Vessi, Ilvarre, Aldric".

## Morphology patterns
- **Patronymics/matronymics**: suffix meaning "child of" (-son, -dai, -ic).
- **Honorifics/titles**: prefixes or standalone (First Speaker, Khan, Prince-Merchant).
- **Place suffixes tied to geography**: -gate (pass), -mark (border), -fjord/-haven (harbor), -sulem (well/oasis), -ford (crossing). These make place-names legible.
- **Compounding**: element + element (High+gate, Szel+gar).

## Consistency method
1. If names already exist in the world (cities, NPCs), list them per people first.
2. Infer the onsets/nuclei/codas actually used by those names.
3. Write the grammar to REPRODUCE them, then extend. New names generated from the grammar should be indistinguishable from the canon ones.
4. Keep peoples distinct: no two cultures should share the same inventory, or names blur together.
